# Evaluation Strategy

## 1. Metrics That Can Always Be Computed

These require no ground truth and are computed for every run:

- **Processing time** (seconds) — measured with `time.perf_counter()` around
  the full pipeline and around each baseline individually.
- **Total native frames vs. candidate frames** — demonstrates the reduction
  achieved by shot-aware sampling before scoring is applied.
- **Candidate reduction ratio** — `candidate_frames / native_frames`.

## 2. Metrics That Require Ground Truth

These are only computed when ground truth is explicitly supplied to
`modules/evaluator.compute_metrics()`; otherwise they are left as `None`
with a note — never fabricated:

- **Shot detection Precision / Recall / F1** — requires a list of true shot
  boundary frame indices. A detected boundary counts as a true positive if
  it falls within `tolerance_frames` (default 5) of a ground-truth boundary.
- **Thumbnail selection accuracy** — requires a ground-truth "ideal" frame
  index; the selected thumbnail counts as correct if within
  `tolerance_frames` of it.

## 3. Human Evaluation (Section 14)

Because "thumbnail quality" is inherently subjective, an optional human
evaluation module is provided:

- Raters score five dimensions on a 1-5 scale: Visual Attractiveness,
  Representativeness, Sharpness, Content Relevance, Overall Quality.
- Ratings are stored in the `evaluation` SQLite table, linked to a specific
  `processing_results` row.
- Mean, median, and standard deviation across raters can be computed directly
  from the stored ratings (e.g. via a small pandas/SQL query) once enough
  ratings have been collected — no synthetic ratings are generated by the
  system itself.

## 4. Comparative Evaluation

The comparison page (`/comparison/<result_id>`) presents, side by side:

- Each baseline's selected frame, its own-scale score, and processing time.
- The CQTR-selected frame, its score, and processing time.
- An explicit note that baseline scores use different internal scales and
  are not directly numerically comparable to the CQTR score — only the
  actual frame choice and relative timing are apples-to-apples.

## 5. Ablation Evaluation

Six configurations (A through F, see `ablation_study.md`) are re-scored
against the *same* extracted candidate set, isolating the marginal effect of
each component. This directly demonstrates whether adding scene
representativeness / content importance changes which frame is selected and
by how much its score shifts.
